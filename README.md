## Задание 1. Реактивность и события

### Упражнение 1.1. Hello Vue

Выведите заголовок с вашим именем, а под ним абзац с названием университета и курса. Данные должны браться из переменных. Добавьте кнопку, которая по клику меняет заголовок на «Заголовок изменён».

### Упражнение 1.2. Счётчик с границами и шагом

Сделайте счётчик, который начинается с 0 и имеет две кнопки — «Увеличить» и «Уменьшить». Значение не должно опускаться ниже 0 и подниматься выше 20. На границе блокируйте нужную кнопку. Добавьте числовое поле для шага — значения, на которое меняется счётчик за один клик. Начальный шаг равен 1.

### Упражнение 1.3. Имя пользователя в реальном времени

Сделайте поле ввода имени пользователя. Под ним показывайте приветствие, которое меняется по мере набора, и количество введённых символов. Кнопка «Регистрация» остаётся заблокированной, пока имя короче четырёх символов. Когда длина достигает 12 символов, количество символов становится красным.

### Упражнение 1.4. Блок, меняющий вид

Сделайте блок с текстом. Кнопка переключает блок между светлым и тёмным режимом с помощью `:class`. Текст кнопки зависит от текущего режима — «Включить тёмный режим» или «Включить светлый режим».

[Открыть приложение](https://annavernadskaya.github.io/vue-homework/) и выбрать «Задание 1».

## Задание 2. Условия, списки и вычисляемые свойства

### Упражнение 2.1. Оценка словами

Сделайте поле для ввода числовой оценки. Рядом покажите статус через `v-if`, `v-else-if` и `v-else`.

| Оценка | Статус |
| --- | --- |
| От 90 до 100 | Отлично |
| От 75 до 90, не включая 90 | Хорошо |
| От 60 до 75, не включая 75 | Удовлетворительно |
| От 0 до 60, не включая 60 | Не сдал |
| Вне диапазона от 0 до 100 | Ошибка: число от 0 до 100 |

### Упражнение 2.2. Список покупок

Сделайте поле ввода и кнопку «Добавить». Добавляйте непустые названия в список и выводите их через `v-for`. Рядом с каждым элементом разместите кнопку «Удалить». Над списком показывайте количество элементов через `computed`. Если список пуст, выводите «Список пуст».

### Упражнение 2.3. Каталог курсов

Дан массив курсов с названием и категорией. Категории — «Программирование», «Дизайн» и «Данные». Сделайте поле поиска по названию и выпадающий список категорий с пунктом «Все». Фильтруйте курсы по обоим условиям одновременно. Если ничего не найдено, покажите сообщение.

### Упражнение 2.4. Статистика оценок

Дан массив студентов. Для каждого покажите кнопки «+5» и «−5». Над списком выведите через `computed` максимальную, минимальную и среднюю оценку, а также количество сдавших (оценка от 60). Для пустого списка вместо максимума и минимума выведите прочерк.

[Открыть приложение](https://annavernadskaya.github.io/vue-homework/) и выбрать «Задание 2».

## Задание 3. Компоненты, пропсы, события и слоты

### Упражнение 3.1. Карточка приветствия

Создайте компонент `GreetingCard` с пропсами `name` (обязательная строка), `age` (число, по умолчанию 18) и `role` (строка, по умолчанию «Студент»). Выведите на странице три карточки через `v-for` по массиву людей. Для одного человека пропустите `age` и `role`, чтобы увидеть значения по умолчанию.

### Упражнение 3.2. Счётчик с событием

Создайте компонент `CounterButton` с пропсами `label` и `step` (по умолчанию 1). Компонент хранит свой счётчик и по клику увеличивает его на `step`. При каждом изменении он отправляет событие `change` с новым значением. В родительском компоненте подключите два счётчика — «Яблоки» и «Груши» с шагом 5. Под ними выведите сумму обоих счётчиков через `computed`.

### Упражнение 3.3. Блок со слотами

Создайте компонент `InfoBox` с тремя слотами:

- `header` с заголовком по умолчанию «Информация».
- Слот по умолчанию для содержимого.
- `footer`, который отображается, только если он передан.

Используйте компонент три раза: без заголовка и подвала, только с заголовком, с заголовком и подвалом.

### Упражнение 3.4. Список задач из компонентов

Сделайте список задач. Компонент `TodoItem` получает пропс `todo` с полями `id`, `title` и `done` и отправляет события `toggle` и `remove`. В `App` хранится массив задач через `useLocalStorage`. Добавьте форму создания задачи, счётчик «Осталось: N» через `computed` и кнопку «Очистить выполненные», которая видна только при наличии выполненных задач.

[Открыть приложение](https://annavernadskaya.github.io/vue-homework/) и выбрать «Задание 3».

## Локальный запуск

В папке проекта, где лежит `package.json`, выполните:

```bash
npm install
npm run dev
```

Откройте адрес, который появится в терминале.
